# 木垒 SLINGHOLD

> 弹弓攻城 · A Tabletop Siege —— 你家桌上立着你的积木城，房间对面是敌人的积木城，双方实时对轰。
> 双手拉弹弓打对方的城，伸手挡开或握拳接住敌弹（接住的就是你的弹药），从补给盘拿积木修自己的城墙。先打倒对方城里的帅旗灯笼就赢。

PICO 手眼 MR 小游戏。一周六款之一（见 `~/Documents/ChatGPT/游戏demo/六款手眼游戏_1123/05_弹弓攻城 PAPER SIEGE.md`，11-24 修订版以它为准）。

## 2. 放 PICO SDK（新克隆工程必做）

把 SDK 6.0.0 的 `XR` 文件夹复制到工程根目录：

```
PaperSiege/
  PICO-SDK/
    XR/          ← 从 ~/Library/PICO/UnitySDK/6.0.0/PICO-Unity-SDK/XR 复制过来
```

`Packages/manifest.json` 里已经写好 `"com.bytedance.pico.xr": "file:../PICO-SDK/XR"`。
**`PICO-SDK/` 已在 `.gitignore` 里，不要提交。**

新克隆后如果打包报错，先把 `Library/Bee` 删掉（里面会留旧的绝对路径）。

## 3. 打开、试玩、打包

```bash
# 打开工程（必须用 Android 目标启动，否则 PICO 的清单处理代码不参与编译、打出来是平面应用）
open -na /Applications/Unity/Hub/Editor/6000.5.5f1/Unity.app --args \
  -projectPath ~/Documents/ChatGPT/PaperSiege -buildTarget Android \
  -logFile /tmp/papersiege-logs/editor.log
```

- **直接点播放** = 桌面试玩（鼠标键盘模拟双手，从标题页开始）。
- 菜单 **PaperSiege → 演示：拉弓发射** = 自动演示（左手举弓、右手续力拉开、松手发射）。
- 菜单 **PaperSiege → Setup Project** = 一键重建工程设置（物理层、调参资源、积木库、主场景）。换机器或改坏了就跑这个。

命令行工具（可选，开发用）：

| 用途 | 命令 |

| 在编辑器里执行一段 C# | `~/.unity/papersiege-tools/cs.py '<方法体>'` |

## 4. 操作（头显）

| 手势 | 做什么 |
|---|---|
| 左手在胸前捏住 | 手里出现 Y 形弹弓（捏着不放，弓就一直在） |
| 右手捏住皮兜、往右肩方向斜着往后拉 | 蓄力（越远越满），出现小木珠组成的预瞄弧线 |
| 右手松开 | 发射（弹从皮兜出发，穿过两叉中间） |
| 张开手掌迎着飞来的敌弹 | 挡开 |
| 敌弹被吸到手边时握拳 | 接住（弹药 +1） |
| 在桌上的弹盒里捏一颗 | 换弹（1 石 / 2 火 / 3 冰 / 4 炸 / 5 分裂） |
| 从补给盘捏一块积木，拿到缺口松开 | 修城（自动吸附） |
| 对着着火的地方往下拍两下 | 灭火 |
| 桌上的地球仪（捏）/ 标题页 | 切换语言 |
| 桌上木牌“音乐”“音效” | 开关 |
| 桌上 10 块积木 | 选关（未解锁的是裸木） |

眼动只做辅助：拉弓时看着敌城的块，弹道轻轻吸过去（≤ 4°）；菜单里只高亮眼睛看的按钮。**没有眼动也能玩完。**

## 5. 可调参数

| 资源 | 调什么 |
|---|---|
| `Assets/_PaperSiege/Resources/InputTuning.asset` | 捏合阈值、握拳 / 张掌判定、跟丢时间、拉弓距离、吸住半径与悬停时长、拍打速度、眼动吸附角度 |
| `Assets/_PaperSiege/Resources/GameTuning.asset` | 两座城的大小与距离、弹的重力 / 半径 / 质量、撞击冲量与苏醒半径、冰冻 / 炸丸 / 分裂参数、弹弓初速与装弹时间、敌人开火间隔 / 蓄力 / 弧顶上限、老实（没弹时）照顾、补给节奏 |
| `Assets/_PaperSiege/Scripts/Runtime/Game/Levels.cs` | 10 关的城布局、开局弹药、敌人打什么弹、帅旗耐久、开火间隔、瞄准误差、时段 |

每次改完 `GameTuning` / `InputTuning` 里的**新字段**，记得在 Inspector 里确认（旧资源文件里新增字段会用代码默认值）。

## 6. 调试工具（编辑器里，运行中也能用）

| 方法 | 做什么 |
|---|---|
| `PSTests.State()` | 一行状态：阶段、剩余时间、弹药、双方完整度 / 帅旗 / 着火 / 在飞弹数 |
| `PSTests.Level(i)` | 直接开第 i+1 关 |
| `PSTests.Quiet()` | 收起模拟手、停火（测试用） |
| `PSTests.Shoot(a, idx, speed, high)` | 从桌面位置往敌城第 idx 块射一发（-1 = 帅旗） |
| `PSTests.Scenario(dir, level, "秒:动作", ...)` | 按游戏时间跑一串 `shoot / snap / log` 步骤 |
| `PSTests.Gestures(dir)` | 模拟手走一遍全部手势（架弓 / 拉 / 射 / 挡 / 接 / 修 / 灭火） |
| `PSTests.TutorialWalk(dir)` | 走一遍第 1 关教学，每一步截图 |
| `PSTests.AllLevels(dir)` | 10 关静置 3 秒测稳定性 + 截图 |
| `PSTests.ReleaseCheck(dir)` | 松手逐帧，量弹到皮兜 / 弓架的距离（验证不穿模） |
| `PSTests.PassthroughCheck(dir)` | 藏掉占位房间、相机清透明，检查天空只画在盒盖开口里 |
| `PSTests.FlowCheck(dir)` | 标题 → 开始 → 赢 → 结算 → 下一关 → 输 → 回标题 |
| `PSTests.Difficulty(n, speed, from, to)` | 难度模拟（机器人 vs AI，真实物理加速跑），含输因（倒旗原因 / 超时）；跑全 10 关写 `Docs/难度模拟.md`，只跑部分关卡写 `Docs/难度模拟_部分关卡.md` |
| `PSTests.EnemyPower(level, n, stone)` | 投石机朝我方城打 n 发、一发不挡，每发后统计离位块数 / 完整度 / 帅旗耐久 |
| `PSTests.TrajCheck()` | 投石机出手点发一发，逐帧对比真实位置和理论弹道 |
| `PSTests.Perf(dir)` | 最大关的渲染物 / 三角面 / 材质数 + 炸丸时最差帧（编辑器数值仅作相对参考） |
| `ShaderKeep.Build()` / `ShaderKeep.Check()` | 生成打包保底材质（`Resources/ShaderKeep/`）/ 检查运行时 `Shader.Find` 是否都有保底。**新增运行时材质写法后要跑一遍** |
| `PSTests.ExportAudio()` | 把合成的音效 / 音乐导出成 wav 到 `Docs/音频试听/` |

截图统一存 `Docs/进度截图/<日期_主题>/`。

## 7. 真机检查清单（装机后 5～10 分钟逐项打勾）

**启动**
- [ ] 启动画面有 MADE WITH + TRIPO（头显里看的是 VR Splash 那张）
- [ ] 标题页在真实房间里，周围是透视画面，只有头顶那块（盒盖）是天空
- [ ] 木梁上的字标、副标题牌、TRIPO 署名牌都看得清，不糊
- [ ] 桌上的 10 块选关积木能看清关号，未解锁的是裸木

**手势**
- [ ] 左手捏住，手里出现弹弓；松开手，弹弓消失
- [ ] 右手捏皮兜，能抓住、能拉开；拉的时候有预瞄弧线
- [ ] 松手发射，弹从两叉中间穿出去（不擦弓架、不穿皮兜）
- [ ] 拉弓时两只手不互相遮挡（右手往右肩斜拉）
- [ ] 敌弹飞到手边，握拳能接住（弹盒里的钉子 +1）
- [ ] 张开手掌能挡开
- [ ] 从补给盘捏积木，放到缺口能补上
- [ ] 对着着火处快速拍两下能灭
- [ ] 手举到眼前 / 放到身侧不跟丢（跟丢 1 秒内操作不中断）

**眼动**
- [ ] 首次启动会弹眼动授权框；授权前游戏照常能玩
- [ ] 拉弓时看着敌城的块，弹道会轻微吸过去
- [ ] 标题页 / 结算页，只有眼睛看的那个按钮亮
- [ ] 关掉眼动权限后，用头部朝向 + 手也能选（退回头部朝向）

**画面**
- [ ] 开场：天花板木板先透出缝，再一条条翻起来飞走，露出当前时段的天空（有过程，不是突然出现）
- [ ] 天空只在头顶那块开口里，四周仍然是真实房间（没有虚拟墙 / 地板把真实房间挡住）
- [ ] 最后一关是夜空 + 月亮 + 星星 + 零星烟花
- [ ] 赢了有烟花，烟花整朵都在天花板以上（火星不落进房间）
- [ ] 输了木板一条条合回来
- [ ] 积木近看：有磨损、有斜角、有磕碰，描边是本色压暗的细线（不是黑板一样粗的黑边）
- [ ] 没有闪烁、没有穿模（积木之间、弹和弹弓之间、手和城之间）
- [ ] 没有粉色 / 看不见的东西：弹和拖尾、烟和火星、示范手、吊绳、弹道点、天空、城墙上的 TRIPO 图标（夜里图标跟着砖一起变暗）

**玩法**
- [ ] 敌方投石机会蓄力（投臂后压、勺子发亮、画出预告弧线）再发射，不瞄准玩家身体
- [ ] 敌弹飞到自己城上方时能挡 / 接；不挡会打到城上、掉块
- [ ] 帅旗被打掉耐久会暗一档、旗子抖一下，扣光才倒下
- [ ] 第三关起帅旗在围起来的小堡里，平射打不到
- [ ] 十关难度递增（城的块数 6 → 96），敌方帅旗耐久 1 → 5；敌人前期主要拆墙，后期才盯着帅旗打
- [ ] 敌弹落在自己城上（不会飞过城落到身后）；预告弧线和实际弹道重合
- [ ] 第 1 关教学：第一发就把对面帅旗砸倒也不会直接判赢，旗躺一下会自己立回去，教学继续到“挡 / 接 / 修”

**界面 / 双语**
- [ ] 切换地球仪，字标一块块翻转成英文；英文不溢出木牌
- [ ] 结算板上的战报（射 / 挡 / 接 / 修 + 三星）字迹清楚
- [ ] 音乐 / 音效开关有效
- [ ] 暂停 / 摘头显再戴上，画面正常

**性能**
- [ ] 第十关（最大城）稳定 72 fps
- [ ] 没有明显的掉帧（尤其放烟花、城倒塌时）

## 8. 已知限制

- 编辑器里没有真实房间，用占位房间代替（白墙、木地板、一张桌子、天花板）。头显上用透视 + 盒盖。
- 真实桌面 / 天花板高度来自 PICO 空间扫描（`RoomTable`）；读不到时退回虚拟桌（桌高 0.85 m、天花板 2.5 m）。编辑器里只能测退回这条路。
- 难度模拟是机器人按“真人能做到的命中率”估的，最终难度要真人试玩后再调。
- 音效 / 音乐全是代码合成，风格是“木头打击乐”，没有配乐级的编曲。
