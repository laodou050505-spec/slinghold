# 音频来源

本游戏的**全部音效和背景音乐都是我们自己用程序合成的**，不使用任何外部录音、采样或音乐素材，没有第三方版权，可商用。

- 离线合成脚本：`Tools/audio/make_audio.py`（Python + NumPy + SciPy + SoundFile），输出到 `Assets/_PaperSiege/Resources/Audio/`
  - `Sfx/<名字>_<n>.wav`：19 种音效，每种 1～4 个变体（运行时随机轮换）
  - `Music/*.ogg`：封面 `title`、六个时段 `tod0`～`tod5`、结局 `ending`，都是无缝循环
- 运行时合成（`Scripts/Runtime/Audio/Synth.cs`、`Music.cs` 的 `Track`）只在上面的文件缺失时兜底。

| 声音 | 怎么合成的 |
|---|---|
| 拉弓 / 捏皮兜 / 松手 | 粘滑摩擦（不规则小冲击 + 共振滤波）= 零星的皮筋“咯吱”；皮革摩擦噪声；松手 = 宽带“啪” + 低频回弹 + 扫频风声 |
| 木块 / 石块被打、积木倒下、整座城塌 | 模态合成（按木 / 石的共振比例排开、各自衰减的正弦）+ 撞击噪声 + 桌面闷响；倒下 = 一串越来越稀的小磕碰 |
| 炸丸 / 冰丸 / 着火 / 灭火 / 烟花 | 低频下滑 + 闷噪声团；密集碎裂冲击 + 玻璃样共振；截止频率先升后落的低通噪声 + 噼啪；拍击 + 柔和蒸汽；远处闷响 + 噼啪 + 大混响 |
| 投石机上弦 / 抛出、接住 / 挡开、放积木、按木签、钉星 | 木棘轮咔嗒 + 绳子吱；低频木头撞击 + 风声；掌心“噗” + 木琴上行五度；手背“啪”；木块“嗒”；拇指琴“叮” |
| 背景音乐（8 首） | 拨弦（Karplus–Strong）、马林巴 / 拇指琴（模态合成）、木笛（正弦 + 气声 + 颤音）、弦乐垫底（加法合成锯齿）、手鼓 / 沙锤 / 铃鼓 / 木鱼；按 A A B A 段落编曲，和弦进行与动机旋律按调式生成，合成混响 + 轻压缩 |

试听：直接播放 `Resources/Audio` 里的 wav / ogg；频谱图在 `Docs/音频试听/频谱/`（检查刺耳高频和头显小喇叭放不出的低频）。
