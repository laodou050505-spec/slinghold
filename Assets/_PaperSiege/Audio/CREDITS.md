# 音频来源

本游戏的**全部音效和背景音乐都是运行时用代码合成的**（`Scripts/Runtime/Audio/Synth.cs`、`Music.cs`），不使用任何外部录音或音乐素材，没有第三方版权，可商用。

| 声音 | 怎么合成的 |
|---|---|
| 木块被打 / 石块被打 / 积木倒下 | 衰减正弦（木头的“咚”）+ 滤波噪声（石头的“咔”）；倒下 = 一串随机间隔的小敲击 |
| 炸丸 / 冰丸 / 着火 / 灭火 / 烟花 | 低通噪声爆音 + 下滑低频；高通噪声 + 高频泛音（冰裂）；起伏的低通噪声（火）；高通噪声（嗤） |
| 拉弓 / 松手 / 投石机蓄力与抛出 | 窄带噪声 + 颤动音调（皮筋吱）；噪声“啪” + 嗡；一下下短敲击（绞盘） |
| 接住 / 挡开 / 按按钮 | 木琴式泛音“叮”；低通噪声“噗”；短敲击“嗒” |
| 背景音乐（6 首，按时段） | 木头打击乐（低鼓、木鱼、沙锤）+ 五声音阶木琴旋律 + 低音，按时段换速度 / 大小调 / 随机种子；16 小节无缝循环 |

试听：编辑器里执行 `PSTests.ExportAudio()`，wav 会导出到 `Docs/音频试听/`（不进安装包）。
