## 11-24 第二轮：磨损做在几何上（用户：结构太简单，要有斜角、磕碰痕，不要崭新，也不能只靠贴图）
做了什么：
- 改成“高模 → 低模”流程（`Tools/blender/ps_wear.py`）：
  1. 形体：每条硬棱一道宽窄不一的平切斜角 + 轻微倒圆；整体轻微歪斜。
  2. 高模：体素重建（0.28 mm）成 20～70 万面，然后在几何上压出凹痕 / 长条压坑、棱上豁口、压塌的角、划痕、木头顺纹裂缝；石块再加成片风化坑洼和麻点；最后再体素重建一次消掉自相交。
  3. 低模：减面到 1800～4400 三角面（大坑和豁口留在轮廓上），对照高模把翻面的小三角形翻回来；LOD1 = 30%（敌城用）。
  4. 逐对烘焙（高模 → 低模，selected to active），烘完向 UV 岛外扩边，棱线写进 mask.A。
- 着色器加 `_BareTint`（裸材色调）：石块偏冷灰，暖光下仍是灰石头。
怎么验证的：逐件检查图（`Docs/进度截图/1124_积木v8_磨损/`）无红点；低模 0 非流形边。
查出并修掉：减面后零星红点（压坑在薄处顶穿 → 二次体素重建）；石块长满青苔、木块整体发暗（逐对烘焙时 AO 被低模挡住 → AO 只算自身）；UV 利用率 30%（改紧凑装箱 → 45% / 53%）。

## 11-25：描边、敌弹出手点（重要）、难度重测、教学漏洞、打包保底
做了什么：
- **描边看不见**：游戏里积木的外轮廓描边和棱线几乎消失（观察场景里有）。对照实验：描边改纯黑 4 像素时清清楚楚 → 几何没问题、是颜色太浅。
  原因：工程是线性色彩空间，“本色 × 0.36”在线性空间乘，人眼看只暗到六成多；描边又不受光，游戏灯光比观察场景暗，正面一暗两者就混在一起，夜里描边反而比正面亮。
  修法（`PSBlock.shader` 的 `LineColor`）：压暗系数按人眼亮度换算（0.36^2.2）；再乘场景亮度（主光 + 环境光），白天 / 黄昏 / 夜里都和受光面保持同样反差。截图 `Docs/进度截图/1125_描边排查/`（修后_L5 白天、修后_L10 夜晚）。
- **城墙 TRIPO 图标夜里发光**：原来是 Unlit，改成 Lit 透明，跟着砖一起变暗（图案本身不改）。
