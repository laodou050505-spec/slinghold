## 11-24 D1：工程骨架 + 积木美术管线
做了什么：
- 工程骨架从《筑天》复制（URP 两档画质、PICO / XR 设置）；PICO SDK 在 `PICO-SDK/`（不入库）；包名 `com.tripoxr.papersiege`，产品名“弹弓攻城”。
- 阴影：两档都改为 6 m、2048；PC 两级级联 + 软阴影，手机 1 级（规范 ≤16 m）。
- **积木建模（Blender 程序化）**：木块 11 种（方块、木板、长梁、方柱、圆柱、拱门、窗块、雉堞、城门、三角屋顶、尖塔顶）、石块 7 种（含刻砖缝的墙、带盾徽浮雕的盾墙）。
  手工感：倒角圆润、角上磕掉几块（只磕外轮廓）、整体轻微歪斜 + 表面低频起伏；细节真刻出来：拼板缝 + 钉帽、拱圈槽、窗台、门板缝 + 门钉 + 门环、方柱 / 圆柱箍线、屋面瓦垄、尖顶五层瓦檐。
- **贴图**：木块一张 2048 图集、石块一张。albedo = 裸木 / 裸石；mask：R 漆面覆盖（石块 = 青苔）、G 缝隙 AO、B 笔触、A 棱线；normal 切线空间。漆色不烘进贴图，Unity 里按块换（8 种材质共用两套贴图，可合批）。
- **着色器 `PaperSiege/Block`**：手绘风柔和明暗（背光面染紫灰而不是变黑）、棱线（mask.A，本色压暗）、外轮廓描边（外扩背面，按屏幕像素保持细线，颜色 = 本色压暗 36% + 提饱和）、预留烧焦 / 余烬 / 冰冻 / 受击闪白。描边沿导入时算的“平滑法线”（UV3）外扩，硬边处不裂开。
