## 11-24 第二轮：磨损做在几何上（用户：结构太简单，要有斜角、磕碰痕，不要崭新，也不能只靠贴图）
做了什么：
- 改成“高模 → 低模”流程（`Tools/blender/ps_wear.py`）：
  1. 形体：每条硬棱一道宽窄不一的平切斜角 + 轻微倒圆；整体轻微歪斜。
  2. 高模：体素重建（0.28 mm）成 20～70 万面，然后在几何上压出凹痕 / 长条压坑、棱上豁口、压塌的角、划痕、木头顺纹裂缝；石块再加成片风化坑洼和麻点；最后再体素重建一次消掉自相交。
  3. 低模：减面到 1800～4400 三角面（大坑和豁口留在轮廓上），对照高模把翻面的小三角形翻回来；LOD1 = 30%（敌城用）。
  4. 逐对烘焙（高模 → 低模，selected to active），烘完向 UV 岛外扩边，棱线写进 mask.A。
- 着色器加 `_BareTint`（裸材色调）：石块偏冷灰，暖光下仍是灰石头。
怎么验证的：逐件检查图（`Docs/进度截图/1124_积木v8_磨损/`）无红点；低模 0 非流形边。
查出并修掉：减面后零星红点（压坑在薄处顶穿 → 二次体素重建）；石块长满青苔、木块整体发暗（逐对烘焙时 AO 被低模挡住 → AO 只算自身）；UV 利用率 30%（改紧凑装箱 → 45% / 53%）。

## 11-24 第三轮：定名《木垒》SLINGHOLD + 道具 + 核心玩法跑通
做了什么：
- 定名（用户）：中文《木垒》，英文 SLINGHOLD，副标题「弹弓攻城 / A Tabletop Siege」；产品名已改。
- 道具 17 件（分支代理做，`Tools/blender/ps_props.py`，同一套几何磨损 + 高模烘低模）：帅旗（旗杆 / 太阳纹布旗 / 灯笼）、投石机（框架 / 投臂 / 轮）、弹弓（树杈 / 皮兜）、5 种弹、补给盘、弹盒 + 钉子、说明木牌。`PSArt.SyncProps()` 同步，材质 M_Props（自发光 = albedo.A）。锚点在 `PropAnchors`。
- 玩法代码（`Scripts/Runtime`）：
  - Castle / Block：按布局搭城，开局全部冻结（kinematic），命中点附近 + 压在上面的一串块才苏醒，停稳 0.6 秒重新冻结；火（每块点着 1～3 块、最多传 3 代、烧透化灰）、冰（冻脆，被撞就碎；浇在火上灭火且不会再着）、炸（石块也能炸碎；冻住的块在范围内全碎）。帅旗倒地 = 倾斜 > 60° 或落到地面。
  - Projectile：自定义重力（0.55 倍，弧线慢、好接）、分裂丸最高点分 3 颗、命中效果、额外冲量。
  - PlayerSling：左手捏 = 弓架；右手捏皮兜拉 = 蓄力 + 预瞄；松手发射；眼动 ≤4° 吸附；跟丢 / 粘连只松弓不发射；弹盒挂在左手下方，右手捏格子换弹。
  - Defense：20 cm 吸住、悬停 0.6 秒，握拳 = 接（+1 弹）、张手 = 挡；往下拍两下灭火（掌心速度改为 80 ms 滑动窗口平均）。
  - SupplyTray：3 块起、20 秒补 1、最多 5；捏起拿到缺口松手 → 补上。
  - EnemyCatapult：4～6 秒一发，蓄力 1.2 秒 + 弹道预告，40% 打帅旗那一列，误差随关卡变小；玩家没弹时变慢。
  - Levels：10 关布局 + 开局弹药 + 敌弹轮换。Director：开局 / 3 分钟 / 输赢。
- 测试工具 `Scripts/Editor/PSTests.cs`：`Scenario`（按游戏时间开火 + 截图）、`Gestures`（模拟手跑全流程）。

怎么验证的：
